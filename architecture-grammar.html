OpenClaw — Runtime + Intelligence
5
⬇️ Signal Ingestion NEW
Normalizes M365 signals into structured context. Enriches with memory — learned patterns, corrections, preferences. Runs overnight batch + real-time.
6
🎯 Cadbury (Orchestrator) NEW
The brain. Decides what to act on, dispatches to specialists, compiles briefings. Consults memory before every decision. Owns the user relationship.
"Good morning, Hema. Your agents handled 47 emails overnight."
7
🧩 Specialist Agents NEW
Mail — session-isolated, never returns raw bodies.
Calendar — coordinates via mesh.
Document — reads, drafts, proposes tracked changes.
Each has scoped permissions. Mail can't read calendar. Doc can't send email.
8
⏸ Trust Gate NEW
Every action passes through. Gate level per action category:
● Auto — newsletters, confirmations, data refresh
● Review — peer replies (graduated over time)
● Locked — exec email, financials, moving others' meetings
44 auto-handled. 2 paused for you. You made 2 decisions.
★
🧠 Memory NEW
Daily logs · LESSONS.md (corrections) · vector search (semantic recall) · SOUL.md (personality). Dream cycles at 4 AM consolidate short-term → long-term.
"Omar has told me MULTIPLE TIMES not to CC legal on draft-stage emails."
