4
Trust Loop The Product
📊 Show the Work
Chain of thought, source citations, confidence signals. User calibrates trust by seeing reasoning, not just results.
⏸ Propose, Never Impose
Agent drafts, user approves. Approval gates scoped by risk level. Never acts on high-stakes decisions without consent.
📝 Learn from Correction
User corrects tone, approach, or judgment. Agent saves the lesson. Won't repeat the mistake. LESSONS.md grows.
📈 Earn More Autonomy
Consistent quality in a category → approval gate removed. Trust is graduated per-skill, not globally. Ratchet, not switch.
Autonomy Spectrum
Not a global dial. Each action category has its own trust level, earned independently through consistent quality.
Action Category Level Behavior Graduation Criteria
Newsletter triage Auto Archive + file without asking —
Meeting confirmations Auto Accept + sync to calendar —
Data refresh Auto Pull latest, index, surface changes —
Reply to peer Review Draft shown, user approves 10 consecutive approvals without edit
Reply to executive Locked Draft shown, always requires approval Never auto — organizational policy
Move someone's meeting Locked Proposes, coordinates with their agent, waits for OK Never auto — affects others
Financial data in emails Locked Flags for human review before sending Never auto — compliance

Show the Work
Not just the result. Chain of thought, sources, confidence. Trust is calibrated through transparency.
Propose, Never Impose
The document is the artifact, not the chat. Every change is a proposal until the human approves.
Context Survives
Chat follows the file. Memory persists across sessions. Switching apps doesn't reset the agent.
Admit Uncertainty
When the agent is stuck, it asks. When it's wrong, it learns. The mistake is valuable. The silence is not.
