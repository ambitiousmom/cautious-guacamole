Tier 1 — Non-Negotiable

Instant or It's Broken

Performance is the foundational UX. If agent mode takes 3+ seconds to become interactive, users go back to the Claude add-in. Every millisecond of delay erodes trust.

Agent Scorecard
🔒 Harness Contract (non-negotiable)
  • <1 second to interactive frame from DAB tap
  • <500ms first token latency after submit
  • Streaming always on — every response streams token-by-token (Harness Cap 1.4)
  • Memory-efficient loading — no BizChat dependencies during frame load
  • Consistent measurement — auth → load → first turn → completion funnel across WXP
Competitive Context Claude sets the bar for streaming UX — smooth, token-by-token, with near-instant first token. The Harness must match this. AugLoop proxy and OfficeBerry container latency are the risks. Bebop's server-first approach with lazy loading is the right architectural direction.

Tier 4 — Delightful

The Model Composes the Interface

Instead of hardcoded UI flows, the LLM selects from a governed catalog of components and returns a JSON payload (SDL) validated against a strict server-side schema. The UI becomes a thin rendering layer. This is architecturally safer than Claude's raw HTML artifact generation — and must feel just as expressive.

Product Direction: The SDL component catalog must be rich enough to cover interactive charts, editable tables, thumbnail selectors, slide previews, code blocks, and forms. The test: can a user modify an interim artifact without typing? If not, it's a presentation, not a tool.

  • Governed SDL schema — server-validated, schema-defined component payloads
  • Component catalog — shared primitives (ChatKit, MAIKit-style) + app-registered domain components
  • Evals for generative UI — correctness, coherence, safety, adaptiveness

  • Word: formatting previews, structure outlines, tone selectors
